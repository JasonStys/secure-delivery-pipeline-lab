# Secure Delivery Pipeline Lab 1.1.0

Created by Jason Stys. This release refreshes the signed, dependency-free inventory-probe example against the source that includes authenticated candidate/active impact review and atomic bounded deployment receipts.

The downloadable `.pyz` is the intentionally small six-member inventory application. The trusted verification, impact and promotion manager is reviewed source code in this repository; it is not silently embedded in an installer. Python 3.12+ and official GitHub CLI are supplied separately. No resident service, desktop installer, production deployment or operating-system signing claim is added.

The release gate requires the versioned lightweight tag to equal current main and the exact returned source/branch/event/workflow identities of successful Validate and CodeQL runs. A newer failure or unfinished run blocks publication even when an older run succeeded. Open code-scanning findings still block release. The release job rebuilds and reruns the unchanged quality/coverage/performance gates, attests the allowlisted assets and requires actual GitHub cryptographic verification before publishing.

The expanded hosted smoke downloads the four allowlisted assets of the existing 1.0.1 baseline and independently selects its source `6e6dc95ce47d4f7dfdf019ccd84db8bdd83f8828`. It authenticates that baseline before execution, reviews the new candidate against it without changing the pointer, promotes the candidate, checks manifest-bound local receipts and idempotent retry, runs actual two-SKU/invalid-price/oversized-file probe controls, then explicitly rolls back to the separately authenticated baseline. Existing tamper and wrong-identity cases remain mandatory. Operator/change aliases in receipts are assertions, not human authentication or signed audit records.

Download `release.json`, `release-probe-1.1.0.pyz`, `sbom.cdx.json` and `validation.json` into a fresh directory. Obtain this tag's full commit independently, then from trusted reviewed verifier source run:

```text
python -m delivery verify --directory DIRECTORY --version 1.1.0 --commit INDEPENDENT_FULL_TAG_SOURCE_SHA
```

Do not substitute checksum/preflight success for authentication. `live-verification.json` is separate public-safe release-job evidence, not a deployment-bundle member. The prior 1.0.1 release/tag/assets remain unchanged. These notes describe required gates; the release workflow's completed result establishes whether publication passed.
