Created by Jason Stys. Publication is gated by exact-source platform/security/CodeQL success and live cryptographic tamper/wrong-identity rejection. Consult the tagged source's README/runbook and the workflow run for actual evidence. Later documentation reports do not change the tagged release's source identity.

Download `release.json`, `release-probe-1.0.1.pyz`, `sbom.cdx.json`, `validation.json` into a fresh directory. From reviewed verifier source, run `python -m delivery verify --directory DIRECTORY --version 1.0.1 --commit INDEPENDENT_FULL_TAG_SOURCE_SHA` before running the zipapp. Requires Python >=3.12 and official GitHub CLI. `live-verification.json` is a separate public-safe release-check report, not a deployment bundle member.

Do not substitute checksums/preflight for authentication. No installer, public backend, production deployment, custom cryptography or SLSA/certification claim. First-public-version rollback has no prior signed public version; fixture rollback tests are explicitly distinguished from live signature tests.
